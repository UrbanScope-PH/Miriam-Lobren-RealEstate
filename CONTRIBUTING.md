# Contributing to UrbanScope

Thank you for contributing to **UrbanScope — Miriam Lobren Real Estate**!

---

## 🛠️ Development Workflow

1. **Branching Strategy**:
   - Always branch off `main` for new features or bug fixes.
   - Use conventional branch naming:
     - `feat/<feature-name>`
     - `fix/<bug-description>`
     - `docs/<documentation-update>`
     - `chore/<maintenance-task>`

2. **Commit Conventions**:
   - Follow standard conventional commits format:
     ```text
     feat(scope): concise description
     fix(scope): concise description
     docs(scope): concise description
     chore(scope): concise description
     ```

3. **Pull Requests**:
   - Open a pull request against `main`.
   - Provide a clear summary of changes in the PR description.
   - Verify all links and routes work properly before merging.

4. **Code Quality & Guidelines**:
   - Refer to [`AGENTS.md`](AGENTS.md) and [`DATABASE.md`](DATABASE.md) for architecture, conventions, and database migrations.
